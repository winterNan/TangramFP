# Vivado GUI projects of the evaluated designs

One Vivado 2018.3 project per design, for the Kintex-7 `xc7k160tffg676-2`. Settings follow the batch
flows behind the paper (`fpga_mac/synth_w.tcl`, `fpnew/synth_fpnew_w.tcl`, `systolic_array/synth_arr.tcl`):

- out-of-context synthesis with hierarchy `rebuilt`
- a 20 ns clock (`xdc/`)
- `Default` placement, then `phys_opt_design` and routing

The projects use the sources of the paper's results:

- MACs: `../rtl/mac`.
- Arrays: `../rtl/array`.
- FPnew: `../fpnew/fpnew_macw.sv` and the FPnew sources cloned into `../fpnew/cvfpu`.

`tb/` holds GUI variants of the testbenches, `xdc/` the clock constraints.

The constraint file is used only in implementation, because the batch flows create the clock after synthesis. With this setting the projects reproduce the batch results exactly, checked for:

- `mac_vi_reg_ce`: 821 slice LUTs, 17.184 ns
- `mac_fpnew`: 597 slice LUTs, 18.011 ns
- `arr4_tfp`: 14,584 slice LUTs, 18.183 ns

## Open a design

    . <Vivado 2018.3>/settings64.sh
    vivado proj/mac_vi_reg_ce/mac_vi_reg_ce.xpr

Create the project first with `make_projects.tcl` (see its header); `proj/` is not part of the repository.

## Simulation

*Run Behavioral Simulation* runs the design on the ResNet18 stream until the trace ends:

- MAC projects use `macw_tb_gui` (`macw_tb` for FPnew).
- Array projects use `array_tb_gui`.

To use another network, change the simulation generic `trace`:

- `../traces/net_<network>.txt` for the MACs
- `../systolic_array/stim/g4_<network>.txt` / `g8_<network>.txt` for the arrays (generated by `systolic_array/run_arrays.sh`)

The outputs are written to `proj/<name>/out_resnet18.txt`.

## Power

The paper's power numbers do not come from the GUI's default *Report Power*, which is vectorless. They use
switching activity from simulation:

- MACs: post-route timing simulation, with SAIF from `fpga_mac/pw_w.sh` and `fpnew/pw_fpnew_w.sh`.
- Arrays: post-route functional simulation, with SAIF from `systolic_array/run_arrays.sh`.

To reproduce them in the GUI, open the implemented design and pass that `.saif` file to *Report Power*. The paper scales the SAIF time unit ×100; see `fpga_mac/power.tcl`.

## Regenerate

    cd evaluation/vivado_projects
    vivado -mode batch -source make_projects.tcl                         # all projects
    vivado -mode batch -source make_projects.tcl -tclargs arr4_tfp       # one project

Regenerating replaces the project and its runs.
